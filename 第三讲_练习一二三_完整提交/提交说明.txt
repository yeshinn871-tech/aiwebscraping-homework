第三讲 · 练习一、二、三 完整提交
==================================

练习一（静态页 · 整站书籍）—— books.toscrape.com
  文件：练习一_books_scraper.py / books_结果.csv / 练习一_运行输出.txt
  过关：抓取 1000 条 = 站点总书量一致，0 缺失，无乱码 ✅

练习二（脏数据清洗 + 入库 + 分析）—— Wikipedia 各国人口
  文件：练习二_脏数据清洗入库分析.py / 练习二_人口排名结果表.csv
        / 练习二_入库数据库.sqlite3 / 练习二_运行输出.txt
  过关：239 行入库（>100）；数字列可计算（SUM=8,073,564,622）；输出排名表 ✅
  要点：千分位逗号→整数、%→小数、脚注/不可见空格、缺失值存 NULL、TEXT/INTEGER/REAL 分列

练习三（动态页 · 内容"等一等才出现"）—— quotes.toscrape.com/js /scroll
  文件：练习三_动态页抓取.py / 练习三_名言抓取结果.csv / 练习三_运行输出.txt
  过关：拿到普通方法抓不到的内容（100 条名言+50 位作者）；一句话讲清机制 ✅
  机制：浏览器执行 JavaScript 而 requests 不执行——内容由 JS 从接口补进去。

共同底线：仅公开沙盒站/Wikipedia；请求加延时控制频率；不碰登录/付费/隐私。
