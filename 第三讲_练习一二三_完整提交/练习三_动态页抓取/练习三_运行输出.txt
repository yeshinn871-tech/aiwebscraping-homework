(B) 内容实际从哪里来？—— 读 <script> 找真相
======================================================================

  [/js] 数据来源：内嵌在 <script> 标签里的 JS 数组 var data = [...]
         直接正则+JSON 解析出 10 条名言，例如：
         "“The world as we have created it is a pr..." —— Albert Einstein

  [/scroll] 数据来源：<script> 里写着 $.get('/api/quotes', {page: page})
           （在浏览器 F12 → Network → XHR/Fetch 也能看到这个请求）
           页面源码里出现 '/api/quotes' 字样 : True
           这就是我们要直接调用的『数据接口』，跳过渲染。

一句话总结（过关标准）
======================================================================
  浏览器会执行 JavaScript，而 requests 不会：名言不是一开始就写在 HTML 里，
  而是页面打开后由 JS 从数据接口（/api/quotes?page=N，/js 则是内嵌数组）补进去的，
  所以直接请求网页拿到的是'空壳'，直接请求数据接口就能拿到真正的 JSON。
